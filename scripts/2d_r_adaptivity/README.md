# 2D plate-with-hole with r-adaptivity

Same problem as `scripts/2d/` (a linear-elastic plate with a central hole pulled
down at the top), but the **mesh node positions are trainable**. Minimising the
elastic potential energy with respect to the interior node positions performs
**r-adaptivity**: the mesh relocates its nodes (topology unchanged) to lower the
energy. All boundary nodes (outer edges and the hole) are pinned so the domain
shape is preserved, and a `FlipLoss` barrier keeps the moving mesh from tangling.

Training runs in two stages:

1. **r-adaptivity** — displacement and mesh optimised jointly (Adam).
2. **refinement** — mesh frozen, displacement refined on the adapted mesh (LBFGS).

## Usage

The mesh is generated by the script in the sibling `2d/` folder:

```bash
# 1. Generate the plate-with-hole mesh into this folder
uv run python scripts/2d/generate_mesh.py -o scripts/2d_r_adaptivity/

# 2. Run the r-adaptive simulation
uv run python scripts/2d_r_adaptivity/main.py \
    -i scripts/2d_r_adaptivity/plate_with_hole.xdmf \
    -o scripts/2d_r_adaptivity/
```

This writes `init.xdmf` (initial mesh + fields) and `result.xdmf` (the adapted
mesh with displacement and recovered stress fields), viewable in ParaView.

## Options

| Flag | Default | Meaning |
| --- | --- | --- |
| `-i`, `--input-mesh` | `./plate_with_hole.xdmf` | Input mesh (xdmf). |
| `-o`, `--output-dir` | `./` | Where `init.xdmf` / `result.xdmf` are written. |
| `--epochs-adapt` | `300` | Joint displacement + mesh (r-adaptivity) steps. |
| `--epochs-refine` | `5` | Displacement-only LBFGS steps on the frozen mesh. |
| `--flip-penalty` | `1e6` | Weight of the anti-inversion `FlipLoss` barrier. |
| `--lr-adapt` | `1e-2` | Adam learning rate for the r-adaptivity stage. |
| `--no-show` | (off) | Skip the interactive loss plot (e.g. for headless runs). |
